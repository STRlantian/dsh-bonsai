# Fold-parameter sweep

Generated by `scripts/sweep-fold-params.mjs 100`. The conversation is synthetic
but every message size is measured with the real DeepSeek v4 tokenizer. Three
profiles are swept:

| profile | new tokens/turn |
|---|---:|
| short | ~1.2k |
| medium | ~4.6k (the profile used in the earlier cost experiments) |
| long | ~10k |

The grid covers `foldAboveTokens` 8k–50k, `foldKeepTurns` 1–4,
`foldBlockRatio` 2–8, and `foldCadence` 1–10: 3,888 rows. Cost uses the same
prefix-cache model as the earlier experiments: hit 0.02/M, miss 1/M, output
excluded. `maxExcess` is the worst cumulative amount by which the plugin is more
expensive than no plugin at any point in the 100 turns.

## What the sweep says

The current default is **not cost-optimal**:

| config (above / keep / ratio / cadence) | short 100t | medium 100t | long 100t | worst excess | break-even |
|---|---:|---:|---:|---:|---:|
| no plugin | 0.3304 | 0.8857 | 1.9782 | — | — |
| **current default** 40k / 3 / 5 / 3 | 0.3062 | 0.6958 | 1.4553 | 0.0351 | 72 / 45 / 34 |
| **recommended** 30k / 2 / 8 / 10 | 0.2916 | 0.6683 | 1.3932 | 0.0251 | 67 / 41 / 30 |
| **cost-first** 30k / 1 / 8 / 10 | 0.2797 | 0.6267 | 1.2933 | 0.0126 | 60 / 30 / 25 |

The three numbers in “break-even” are short / medium / long.

At the 60-turn horizon used by the earlier comparison:

| config | short | medium | long |
|---|---:|---:|---:|
| current default | 0.1768 | 0.4028 | 0.8465 |
| recommended | 0.1728 | 0.3870 | 0.8113 |
| cost-first | 0.1657 | 0.3675 | 0.7644 |

The cost-first setting is the cheapest in every profile, but it keeps only the
last turn and relies on `retrieve_context` for older context. The recommended
setting keeps two turns, folds less often, and still beats the old default by
4–5% over 100 turns.

**Recommendation:** use `foldAboveTokens: 30000`, `foldKeepTurns: 2`,
`foldBlockRatio: 8`, `foldCadence: 10` as the balanced default. Keep
`30000 / 1 / 8 / 10` as the cost-first option for people who prefer the smallest
prompt and accept one-turn context.

The full grid is in `fold-param-sweep.csv`.
